A retro CRT terminal WordPress theme: glowing phosphor-green text on a black screen, with scanlines, a typing command prompt and a hacker-blog layout.

== Description ==

Retro Hacker Terminal turns your blog into an old-school computer terminal. Green monospace text glows on a black background, with CRT scanlines, vignette and flicker, a live typing prompt, and a system-info style footer. Fully responsive, with a mobile menu, and no jQuery.

= Features =
* Phosphor-green on black CRT look (VT323 and Share Tech Mono fonts)
* Scanlines, vignette, glow and flicker effects
* Typing terminal prompt bar
* Right sidebar that stacks on tablet and mobile
* Responsive navigation with a mobile toggle and a search drop-down
* Green-tinted post images
* Configurable post counter (Customizer > Terminal Counter)
* Lightweight vanilla JavaScript

== Installation ==
1. Appearance > Themes > Add New > Upload Theme.
2. Choose the ZIP and click Install Now, then Activate.
3. Create a menu under Appearance > Menus and assign it to the Primary location.
4. Add widgets under Appearance > Widgets (a default sidebar is shown if none are set).
