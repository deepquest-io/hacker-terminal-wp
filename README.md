# Retro Hacker Terminal

> A fully responsive retro CRT terminal WordPress theme. Glowing phosphor-green text on a black screen, with scanlines and a typing command prompt.

Retro Hacker Terminal turns a WordPress blog into an old-school computer terminal: green monospace text on pure black, CRT scanlines, vignette and flicker, an animated typing prompt and a system-info footer. It is fully responsive (phone, tablet and desktop), lightweight and uses no jQuery.

Made for hacker, security, dev, retro-computing and cyberpunk blogs.

## Features

- Phosphor-green on black CRT look (VT323 and Share Tech Mono)
- Scanlines, vignette, text glow and screen flicker
- Typing terminal prompt bar (`root@yoursite:~#`)
- Right sidebar with category, archive and counter widgets (counter title and category configurable in Appearance > Customize > Terminal Counter)
- Fully responsive: desktop, tablet and phone layouts (tested 320px to 1440px, no horizontal scroll), hamburger menu, 44px touch targets, fluid images, scrollable code blocks and tables
- Custom 404 page with a harmless hacking-terminal simulation (fake output, respects reduced-motion)
- Nav bar search drop-down
- Green-tinted images, styled code blocks, comments, pagination and tables
- Vanilla JavaScript, no jQuery, no external JS libraries
- No WordPress or PHP version exposed in the front-end

## Installation

1. Download the latest ZIP from [Releases](../../releases), or zip the `deepquest-terminal-theme` folder.
2. In WordPress go to **Appearance > Themes > Add New > Upload Theme**, install and activate.
3. Create a menu in **Appearance > Menus** and assign it to **Primary Menu**.
4. Add widgets in **Appearance > Widgets**. A default sidebar is shown if none are set.
